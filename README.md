# Minara feature videos

Source projects behind Minara product-launch videos and DMind Benchmark films. HTML, CSS, GSAP, HyperFrames, and Remotion compositions sit alongside storyboards, reusable motion examples, assets, and versioned exports.

## Projects

| Project | Contents |
|---|---|
| [Harness launch film](harness-1min-scenes/) | Desktop product launch scenes, storyboard, and Remotion workspace |
| [App 2.0](app-2.0-video/) | Mobile product launch compositions, review tools, and voiceover |
| [DMind Benchmark KDD](dmind-benchmark-kdd/) | Earlier dark-blue benchmark film and individual scene exports |
| [DMind Benchmark](dmind-benchmark-video/) | Later light/pastel benchmark film and complete video export |
| [Cross-sectional factors](minara-cross-sectional-factors/) | English factor-strategy video sources and exports |
| [Cross-sectional factors: Japanese](minara-cross-sectional-factors-jp/) | Original Japanese sources and media |
| [Cross-sectional factors: Korean](minara-cross-sectional-factors-kr/) | Placeholder: the supplied source folder contained no project files |
| [Cross-sectional factors: Chinese](minara-cross-sectional-factors-zh/) | Original Chinese sources and media |
| [Strategy Studio 2](minara-strategy-studio-2/) | Strategy Studio feature-video source and exports |

Read each project's README for its entry point and preview instructions. These are independent production snapshots, not a single application. Dependencies are installed per project; there is no shared build. Large media files are included, so the initial clone may take a few minutes.

## Archive scope

The original working folders were copied without modification. Completed English translations are included; some production notes retain their original language because publication was prioritized over finishing translation. Japanese and Chinese projects intentionally retain their localized content.

Private production records, credentials, machine-specific browser state, installed dependencies, and disposable render caches are excluded. Project READMEs describe additional omissions or incomplete source material. Historical drafts and placeholder benchmark figures are production artifacts, not current product or research claims.
