# Minara App 2.0 — Timeline Framework & Storyboard v03

## Production rules

- The draft and every screenshot are direction only. Final UI must be rebuilt in English as original Silicon Valley-style mobile product UI.
- Default canvas is `#F7F7F7`; typeface is Geist throughout; color language is black, white and gray unless a scene explicitly calls for semantic green, deep navy, or the approved `2.0` gradient.
- No Three.js. Use flat oversized mobile UI with an iPhone 17 outer frame; the phone and key controls may exceed frame bounds.
- “Camera zoom” always moves the complete phone rig: `scale 0.96 → 2.25`, `y 0 → -756`, `x 0`, `0.78s`, `power3.inOut`.
- Text entrance always uses the opening blur-pop: `opacity 0→1`, `y 24→0`, `scale .94→1`, `blur 12px→0`, `0.58s`, `power3.out`, phrase stagger `0.18s`.
- Runtime randomness is forbidden. Profit values and repeated events use seeded deterministic sequences.
- Mobile screens use the canonical four-item bottom navigation recorded in `context.md`: Profile, Discover, Strategies, Wallet. Use real SVG UI icons and the compact input-to-navigation spacing from Shot 03; never use placeholder glyphs.
