# Minara App 2.0 Video

Public backup of the App 2.0 HyperFrames source, review tools, reusable assets, and versioned media outputs.

## Run

- Open `review/app2-timeline-editor.html` directly in a browser to edit the storyboard timeline.
- Serve the project directory with `python3 -m http.server 4014` when a browser needs HTTP-relative assets.
- Render an existing HyperFrames composition from its directory with `npx hyperframes render --output <output>.mp4`.

The project has no package manifest; it uses the locally available HyperFrames CLI and browser runtime. The source review pages are paused compositions and do not require a development server when opened directly.

## Included

English project notes, storyboard and timeline review pages, source screenshots, HTML/CSS/SVG test compositions, reusable examples, local fonts/vendor assets, final narration/audio files, and versioned MP4 renders.

## Excluded

Private context, agent and change-log files; Git metadata; dependency folders; browser state and caches; QA snapshots and disposable frame sequences; draft-analysis/reference montages; intermediate voiceover assembly files; and superseded visual-direction/style-board documents.

The review UI and camera-zoom example were translated to English. Older source material that was intentionally excluded may still contain the original language. Media was preserved as supplied and was not re-rendered during this backup.
